# Чеклист «агента на пять звёзд» — что есть в agentkit

✅ сделано и покрыто тестами · 🟡 сделано частично или без проверки на живом окружении · ❌ ещё нет

## 1. Агентный цикл — `agent.py`

| | Что | Где / как |
|---|---|---|
| ✅ | Цикл модель → инструменты → результат → модель | `Agent._loop` |
| ✅ | Условия остановки: ответ без инструментов, лимит шагов, отмена, ожидание человека | `RunStatus` |
| ✅ | Последний шаг без инструментов — модель обязана подвести итог; в сервисе по умолчанию 150 шагов | `max_steps`, `AGENT_MAX_STEPS` |
| ✅ | Параллельные вызовы: подряд идущие read-only — одновременно, остальные по порядку | `_execute` |
| ✅ | Стриминг текста и рассуждений | `TEXT_DELTA`, `THINKING_DELTA` |
| ✅ | Повторы с backoff (429/5xx/обрыв), переход на запасную модель | `ModelRouter` |
| ✅ | Отмена в любой момент | `Agent.cancel`, кнопка «стоп» |
| ✅ | Ошибка инструмента → текст модели, а не падение | `_invoke` |
| ✅ | Защита от зацикливания (N одинаковых вызовов) | `loop_guard` |
| ✅ | Заплатка истории, если процесс упал между вызовом и результатом | `_for_model` |
| ✅ | Прогоны-сироты после перезапуска помечаются ошибкой (только без живой блокировки — соседние процессы не задеваются) | `AgentService._fail_orphans` |
| ✅ | Уровень рассуждений (effort) | `AgentSpec.reasoning_effort` |
| ✅ | Дописать сообщение, пока агент работает: очередь в базе, агент читает её между шагами (не разрывая пары вызов-результат) и перед «готово»; иначе — сразу после прогона | `ak_inbox`, `Agent._take_inbox`, `AgentService.send` |

## 2. Контекст — `context.py`

| | Что | Где / как |
|---|---|---|
| ✅ | Системный промпт из слоёв: правила ядра → промпт агента → правила хоста → skills → MCP → отложенные инструменты → окружение → память | `build_system_prompt` |
| ✅ | Порядок под кэш: стабильное первым, дата (без времени) и память — в конце | там же |
| ✅ | Prompt caching для Claude через OpenRouter (cache_control на системном и последнем сообщении) | `openai_compat._with_cache_control` |
| ✅ | Автосжатие истории моделью small; история в базе не теряется | `compact`, `effective_history` |
| ✅ | Обрезка длинного вывода + полный текст в blob, чтение по частям | `truncate_text`, `read_output` |
| ✅ | Отложенные инструменты: в промпте имя, схема — через `tool_search` | `registry.py` |
| ✅ | Учёт токенов и стоимости по шагу, прогону, пользователю, модели | `Usage`, `/api/usage` |
| 🟡 | Оценка токенов без токенизатора (±25%) | достаточно для порога сжатия |

| ✅ | Виджеты в ответе инструмента: таблица, kv, картинки, выбор | `ToolResult.ui` |
