# Еженедельный обзор

1. Найди все заметки (notes_search без запроса).
2. Отбери созданные за последние 7 дней.
3. Сгруппируй по темам; повторы и почти-дубли отметь отдельно.
4. Ответ — по шаблону `template.md` из этого skill'а.
5. Ничего не удаляй сам — только предложи номера для удаления.
